# PID-Controlled LMS Adaptive Echo Cancellation

MATLAB simulation of an adaptive echo cancellation system using an LMS filter with a PID-controlled step size.

## Overview

This project implements an echo cancellation system in MATLAB using a PID-controlled LMS adaptive filter.

An FIR filter is used to model the echo path, while the microphone signal is generated by combining the echoed signal with background noise. The LMS adaptive filter estimates the echo and reduces it from the microphone signal.

A PID controller dynamically adjusts the LMS step size based on the residual error power to achieve faster convergence and stable performance.

## System Flow


Far-End Input
      ↓
  Echo Path
   (FIR Filter)
      ↓

      ↓

      ↓
